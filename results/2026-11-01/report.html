How to read this page
Each grid is one measurement: rows are models, columns are the three KV cache types. A cell's number is that arm's result, and its colour is the same number on a 0–100 scale — green = good, red = bad. For the first two grids higher is better; for the loop grid lower is better, so its colours are inverted. Hover any cell for the exact value.
What the tabs hold: Matrix — the 15-arm comparison, the change versus f16, and how often two arms gave the identical answer. Tasks — the same data per task, so you can see which task carried a difference. Loops — every sample the repetition detector flagged, with the exact text that repeated, so you can judge it yourself.
Three facts that make the numbers honest: differences of a few points are noise; the semver code task moves by tens of points on a single design decision; and Gemma's q4_0 code score is a generation-length cut-off, not wrong code. The prose summary, with those caveats written out, is docs/RESULTS.md.
